# Firmware symbol map (E-M10 Mark I, body fw 1.4)

Master index of **named / confirmed** runtime symbols recovered by static RE of the decoded firmware
container (`OLY_E_113_1400_0000_0000.BIN`). One place to look up "what lives at address X" and to see
coverage. Per-subsystem detail lives in the linked docs; this file is the cross-reference.

- **Runtime base = `0x7d991020`.** Block-0 code/data resolve at `fileoff + 0x7d991020` (NOT the
  container's stated load `0x40300000`; xrefs only resolve against `0x7d991020`). See
  `docs/firmware/memory-map.md`, `docs/firmware/flash-storage.md`.
- Architecture: Panasonic MN10300 / AM33. Immediates render **decimal** in our objdump build.
- Regenerate the full address→doc index with `python3 -I tools/symbol_index.py` (or
  `--once 0x7de57532` to locate one address). This curated table is the important subset.

## "filemem" media/file memory block pool
Dedicated fixed-block allocator for the **file/media subsystem** ("filemem"), living in the
`0xa0a8xxxx` RAM region (distinct from the general `pool_alloc_block` pools). IRQ-safe (`irq_save

`==== filemem_small/medium ====`, `sign: ____ size: %d addr: 0x%08x`, `used block: %d`,
`free block: %d`.

## Size-classed fixed-block buffer-pool allocator
IRQ-safe fixed-block pool allocator with two size classes. `d0` = requested size, `d3` = caller tag
stored in the pool's link table. Wrapped in a critical section (`irq_save 0x7d9c580c` / `irq_restore
0x7d9c5851`). Each class is a free-list of fixed blocks: pop head index, relink, compute block
address = `base + index*blocksize`, bump in-use count and peak high-water. Failure returns a module
`0x15B` error code (via error logger `0x7da91d8d`), never a pointer.
- **128-byte class** (`size<=128`): head `0x606b8fd8`, link table `0x606b8fec`, block array
  `*(0x606ba6a4)` (×128), in-use `0x606b8fda`, max-tag `0x606b8fdc`, peak `0x606b8fde`;
  empty → err `0x15B00001`.
- **512-byte class** (`128<size<=512`): head `0x606b8fe0`, link table `0x606b907c`, block array
  `*(0x606ba6a8)` (×512); empty → err `0x15B00002`.
- `size>512` → err `0x15B00003` (unsupported).
